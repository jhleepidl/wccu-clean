# Licensing

The author-developed code has no project-wide license at present; see [LICENSE](LICENSE).
Third-party code retains the terms listed in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
The project license status does not change the terms for external datasets, model
weights or tokenizer assets.

[GitHub's repository licensing documentation](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)
explains the distinction between publishing source code and granting an open-source license.
